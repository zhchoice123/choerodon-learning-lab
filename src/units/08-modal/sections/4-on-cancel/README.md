# 08-4 取消：回滚与移除草稿

## 这一节学什么

弹窗里的 Form 直接编辑记录，输入时列表就同步显示草稿。点「取消」时，要把草稿撤销干净。

## 核心概念

```js
const isNew = record.status === 'add';   // 打开时记下
onCancel: () => {
  record.reset();                        // 回到最近一次保存的值
  if (isNew) ds.remove(record);          // 新增的还要移除
  return true;
},
```

| 场景 | 只 `reset()` 的结果 |
|---|---|
| 编辑已有记录 | 恢复成功 |
| 新增记录 | 字段清空了，但**这一行还在列表里**（状态仍是 add） |

`reset` 恢复的是「最近一次保存的值」，不是「打开弹窗那一刻的值」：如果打开前就有未保存修改，也会一起被撤销。

## 看样例

1. 编辑改名后点「取消」：表格恢复原名
2. 点「新增角色」再「取消」：多出来的那行消失
