# 08-1 Modal.open：弹窗与抽屉

## 这一节学什么

用代码打开弹窗或抽屉，在里面放表单。

## 核心概念

```js
const modal = Modal.open({
  title: '查看角色',
  drawer: true,                   // 抽屉；不写就是居中弹窗
  children: <Form record={record}>...</Form>,
  okCancel: false,                // 只要「确定」
});
// modal.update({...}) 更新，modal.close() 关闭
```

| 要点 | 说明 |
|---|---|
| 是函数，不是组件 | 不用写在 JSX 里，调用就打开 |
| 返回句柄 | 可以 `update`、`close`；**不是**表示保存结果的 Promise |
| `drawer` | 只改变外观，表单和回调写法完全一样 |

## 看样例

选中一个角色，分别点「弹窗查看」「抽屉查看」：内容相同，一个居中，一个从右侧滑出。

## 练习

用抽屉查看当前员工（1 个 TODO）。
