# 08-5 稳健的弹窗：失败、重复点击、卸载

## 这一节学什么

真实业务里弹窗要经得起三种意外：后端拒绝、用户连点、用户中途离开页面。

## 核心概念

| 意外 | 处理 |
|---|---|
| 后端拒绝保存 | `onOk` 返回 `false` 留窗，提示 `feedback` 里记下的原因 |
| 用户连点「确认」 | 用 `pending` 标志位，保存期间直接 `return false` |
| 切到别的页面（组件卸载） | `useEffect` 的清理函数里 `modal.close()`，只关自己的 |

```js
useEffect(() => () => modalRef.current && modalRef.current.close(), []);
```

不要在卸载时用 `Modal.destroyAll()`：它会把别的模块打开的弹窗也关掉。
已经发出去的保存请求，不会因为关闭弹窗而撤销。

## 看样例

名称改成 `FAIL` 确认：弹窗不关，弹出「保存失败」和后端原因；改回正常名称再确认，保存成功。
