# 08-2 绑定捕获的记录

## 这一节学什么

弹窗打开期间，列表的当前行可能被别的代码改掉（定时刷新、快捷键、其他组件……）。
弹窗要编辑的，必须是**打开那一刻**的那条记录。

## 核心概念

```js
const record = roleDS.current;           // 打开时捕获
Modal.open({ children: <Form record={record}>...</Form> });
```

| 写法 | 弹窗编辑的是 |
|---|---|
| `<Form dataSet={ds}>` | `ds.current`，**会变** |
| `<Form record={record}>` | 打开时捕获的那一条，**不会变** |

保存时同样要用捕获的 `record`，不要在点确认时重新取 `ds.current`。

## 看样例

打开编辑后点「（演示）切换列表的当前行」：表格高亮行变了，表单仍是原来的角色。
