# 09-5 优先级：DataSet 属性优先于全局

## 这一节学什么

全局配置和 DataSet 自己的属性同时存在时，**DataSet 自己的优先**。

## 核心概念

| 写在哪 | 优先级 |
|---|---|
| DataSet 的属性（如 `dataKey`） | 高 |
| 全局 `configure` | 低：DataSet 没写时才用 |

这条规则有两面：
- **好处**：个别特殊接口，在它自己的 DataSet 上单独写，覆盖全局
- **隐患**：从别处复制来的 `dataKey`，会悄悄盖住全局配置，排查时很难想到
