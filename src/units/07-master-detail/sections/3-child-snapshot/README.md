# 07-3 子表快照：切换头保留草稿

## 这一节学什么

在多个头之间来回切换编辑行，每个头的修改都要保留，最后一起保存。

## 核心概念

```js
const switchTo = (index) => {
  roleDS.current = roleDS.get(index);   // 只做这一件事
};
```

| 框架自动做的事 | 说明 |
|---|---|
| 第一次切到某个头 | 查询它的行 |
| 切回已经加载过的头 | 恢复它的**快照**（包括未保存的修改），不再请求 |

**不要**在切换后手动 `子表.query()`：它会用后端的数据覆盖快照，草稿就没了。

## 看样例

改第一个角色的权限说明 → 切到第二个 → 切回来：改动还在，「主从整体有修改」始终为 true。
