# 04-3 只读：readOnly 与 Output

## 这一节学什么

同一张表单经常需要「查看 / 编辑」两种模式，或者旁边放一个只读预览。

## 核心概念

| 写法 | 作用 |
|---|---|
| `<Form readOnly>` | 整张表单只读；切换回编辑，草稿还在 |
| `<Output name="..." />` | 永远只读，只显示值 |
| `<Form record={record}>` | 显式绑定一条记录，优先于 `dataSet` / `current` |

`readOnly` 只锁住**界面输入**，程序里调用 `record.set` 仍然可以改值。

## 看样例

1. 改名称后切换为只读：输入框变成文本，内容是改过的
2. 下方预览一直是只读，和表单显示同一条记录
