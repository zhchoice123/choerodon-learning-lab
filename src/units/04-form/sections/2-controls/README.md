# 04-2 常用控件：与字段类型配合

## 这一节学什么

不同类型的字段要用对应的控件，写进记录的值类型才正确。

## 核心概念

| 字段 | 控件 | 写入的值 |
|---|---|---|
| `string` | `TextField` | 字符串 |
| 有 `options` | `Select` | `valueField` 的值 |
| `number` | `NumberField` | 数字 |
| `date` | `DatePicker` | 日期 |
| `boolean` | `Switch` | `true` / `false` |

用错控件的常见问题：数字字段用 `TextField`，记录里存的会变成字符串；布尔字段用 `TextField`，根本没法正确编辑。

## 看样例

改「成员数」、切换「启用」：状态栏显示记录里存的值，类型分别是 `number`、`boolean`。
