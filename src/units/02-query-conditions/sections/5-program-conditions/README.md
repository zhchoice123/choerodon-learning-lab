# 02-5 用代码控制查询

## 这一节学什么

除了在查询栏里手动输入，业务里常常要用按钮一键设置条件，或者恢复默认。

## 核心概念

```js
roleDS.queryDataSet.current.set({ level: 'project' }); // 修改条件
roleDS.queryDataSet.current.reset();                    // 恢复初始值
roleDS.query(1);                                        // 主动从第 1 页查询
```

- 修改条件**不会自动查询**，一定要调用 `query`
- 传 `1` 从第 1 页开始：在第 3 页改了条件，新结果可能根本没有第 3 页

## 看样例

1. 翻到第 2 页，点「只看项目层」：请求带 `level=project`，回到第 1 页
2. 点「恢复默认」：条件清空，查询全部角色
