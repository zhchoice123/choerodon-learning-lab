# 06-4 联动赋值：record.set

## 这一节学什么

一个字段变化时，自动修改其他字段：清空已经失效的子值、带出关联信息。

## 核心概念

```js
events: {
  update: ({ record, name, value }) => {
    if (name === 'scope') record.set({ permission: undefined, summary: '' });
    else if (name === 'permission') record.set('summary', 找到的选项名称);
  },
}
```

| 原则 | 原因 |
|---|---|
| 父字段变了要**显式**清空子值 | 下拉组件只在特定条件下自动清理，不能指望它保证数据一致 |
| 联动**单向** | `record.set` 也会触发 update；A 改 B、B 又改 A 会死循环 |
| 修改**事件里的 record** | 下一节专门讲 |
