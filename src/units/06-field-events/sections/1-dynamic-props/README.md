# 06-1 动态属性：dynamicProps / computedProps

## 这一节学什么

字段的属性不一定是固定的：可以根据记录里其他字段的值动态计算。

## 核心概念

```js
{
  name: 'owner',
  dynamicProps: {
    required: ({ record }) => record.get('enabled') === true,
    disabled: ({ record }) => !record.get('enabled'),
  },
}
```

| 写法 | 特点 |
|---|---|
| `dynamicProps: { 属性: ({ record }) => 值 }` | 每次读取时计算 |
| `computedProps: { 属性: ({ record }) => 值 }` | 写法相同，带 MobX 缓存 |

- 按**属性**写函数，不要用已经废弃的「整个对象一个回调」写法
- 同一个属性不要在两处重复定义
- 动态属性只影响界面和校验，`record.set` 仍然能改值
