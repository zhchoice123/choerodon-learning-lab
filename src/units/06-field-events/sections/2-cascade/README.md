# 06-2 级联下拉：cascadeMap

## 这一节学什么

「省 → 市」「部门 → 小组」这类下拉：选了父级，子级只显示属于它的选项。

## 核心概念

```js
{
  name: 'permission',
  options: permissionOptions,        // 每个选项带 scopeCode
  cascadeMap: { scopeCode: 'scope' }, // 选项.scopeCode === 本条记录.scope
}
```

| 位置 | 是什么 |
|---|---|
| 左边（键） | **选项数据**里的字段 |
| 右边（值） | **当前记录**里的父字段 |

父字段为空时，子下拉没有可选项。级联只在本地过滤选项，不会重新请求。

## 看样例

1. 不选范围，打开「权限」：没有选项
2. 范围选「项目」：权限只有「项目查看」「项目编辑」
