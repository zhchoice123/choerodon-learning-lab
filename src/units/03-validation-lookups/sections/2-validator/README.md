# 03-2 自定义 validator：同步与异步

## 这一节学什么

内置规则表达不了的校验（比如「去掉空格后至少两个字」「编码不能重复」），用 `validator` 自己写。

## 核心概念

```js
validator: (value, name, record) => !value || value.trim().length >= 2 || '至少两个字',
```

| 返回值 | 含义 |
|---|---|
| `true` | 通过 |
| 字符串 | 不通过，字符串就是提示 |
| `Promise` | 异步校验：校验会等它完成，结果同上 |

异步校验的两个原则：

1. **空值和格式问题交给 required / pattern**，validator 直接返回 `true`，避免一个问题两套提示
2. **网络失败、服务异常要返回失败提示**，不能当作「通过」放行

## 看样例

1. 名称只填一个字：提示至少两个字符
2. 编码 `site-admin`：等一会儿提示「已存在」；`learning-role` 通过
3. 编码 `service-down`：提示服务暂不可用，结果为「未通过」
