# 01-5 useMemo：DataSet 只创建一次

## 这一节学什么

函数组件每次重新渲染，**整个函数体都会从头执行一遍**。
如果在函数体里直接 `new DataSet(...)`，每次渲染都会得到一个全新的 DataSet。

## 核心概念

```js
const roleDS = useMemo(() => createRoleDataSet(), []);
```

依赖数组是 `[]`：只在第一次渲染时执行工厂函数，之后一直返回同一个 DataSet。

每次都新建 DataSet 的后果：

| 后果 | 原因 |
|---|---|
| 勾选、当前行丢失 | 新的 DataSet 里没有这些状态 |
| 重复发请求 | 每个新 DataSet 都会 autoQuery |
| 表格闪烁、翻页回到第 1 页 | 数据被整份替换 |

## 看样例

点「重新渲染」：「直接创建」的次数一直增加，「useMemo 创建」始终是 1。
