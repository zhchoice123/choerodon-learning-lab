# 01-1 字段类型：fields

## 这一节学什么

DataSet 用 `fields` 描述数据里的每一个字段。同一个值，`type` 不同，表格里的显示就不同。
本节的数据直接写在 `data` 里，不发请求，只关注字段本身。

## 核心概念

```js
fields: [
  { name: 'memberCount', type: 'number', label: '成员数' },
]
```

| 属性 | 作用 |
|---|---|
| `name` | 对应数据里的键，大小写必须一致 |
| `label` | 列标题、表单标签，都从这里来 |
| `type` | 决定显示和校验方式 |

| type | 适合的值 | 表格里的显示 |
|---|---|---|
| `string` | 文字 | 原样显示 |
| `number` | 数字 | 右对齐 |
| `boolean` | `true` / `false` | 勾选框 |
| `date` | 日期 | `2023-06-01` |
| `dateTime` | 日期 + 时间 | `2023-06-01 00:00:00` |

## 看样例

1. 「成员数」右对齐，「启用」是勾选框：这是 `number` 和 `boolean` 的效果
2. 「创建时间」带时分秒：`dateTime`
3. 列标题全部来自 `label`，`columns` 里没有写标题
