# 01-4 响应解析：dataKey / totalKey

## 这一节学什么

后端返回的不只是一个数组，还带着总条数、页码等信息。
DataSet 要知道**列表在哪个字段**、**总数在哪个字段**。

## 核心概念

```text
{ "content": [ ...5 条... ], "totalElements": 12, "totalPages": 3, ... }
       ▲ dataKey                    ▲ totalKey
```

| 配置 | 默认值 | 本项目接口 |
|---|---|---|
| `dataKey` | `rows` | `content` |
| `totalKey` | `total` | `totalElements` |

没配时找不到 `rows`，DataSet 就把**整条响应当成一条记录**，所以表格只有一行空白数据。

## 看样例

1. 左边：只有 1 行空白记录，分页器显示 1 条
2. 右边：5 行数据，分页器显示共 12 条
3. 两边请求的是同一个接口，区别只在两行配置
