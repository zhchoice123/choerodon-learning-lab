# 01-7 常用实例成员

## 这一节学什么

写业务代码时最常用的几个 DataSet 实例成员。

## 核心概念

| 成员 | 说明 |
|---|---|
| `query(page?)` | 查询指定页；**不传参数回到第 1 页** |
| `currentPage` / `totalPage` / `totalCount` | 当前页、总页数、总条数 |
| `current` | 当前行（点击行时变化），可能为空 |
| `selected` | 勾选的记录数组 |
| `record.get(name)` | 读取一条记录的字段值 |

## 看样例

1. 翻到第 2 页，点「刷新当前页」：仍在第 2 页（`query(currentPage)`）
2. 勾选几行，点「查看选中」：用 `selected` + `record.get` 拼出编码
