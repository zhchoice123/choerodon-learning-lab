### 本次发现并修复：CI 串行运行时 Node 进程崩溃

- 现象：`--runInBand` 下 jest 在所有测试文件执行完后崩溃（退出码 1，没有测试汇总），GitHub CI 每次都会失败；并行运行不受影响，所以之前没有发现
- 根因：`src/App.test.js` 打开 `#/unit-09` 验证路由。单元 09 开放后，练习预览里的 DataSet 会发出真实请求；
  jsdom 没有服务器，请求在该测试文件结束后才失败，失败提示 `message.error` 访问已销毁的 document，导致进程崩溃
- 修复：`App.test.js` 与其他测试文件一样只替换 DataSet 的 HTTP 层，并在用例内等待请求完成（已包含在 `058a493`）
